# zomato-partner-clone-

A responsive clone of the Zomato Restaurant Partner Dashboard built with Vanilla HTML5, CSS3, and JavaScript.

## Features
- **Orders**: Live order management (Accepted, Food Ready, Picked up, etc.)
- **Menu Overview & Editor**: Menu score gauge, item categorisation, pricing, inventory toggles
- **Order History & Search**: Search and filter past customer orders
- **Reporting**: Performance metrics, sales breakdown, and interactive Report Generation modal with export
- **Offers**: 
  - *Create offers*: Promo codes and freebies creator
  - *Track offers*: Filter tabs (Active, Scheduled, Inactive, All), performance metrics (Gross sales, Orders delivered, Discount given, Effective discount %), and stop offer action
- **Finance, Ads, Hyperpure, & Outlets**: Dedicated management views
